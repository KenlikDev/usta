# Usta

Usta is an open-source desktop 3D creation tool focused on modeling, with a possible future path toward a game engine and tools for architects, engineers, and designers.

> **Project status:** early foundation stage. The repository currently contains planning documentation, not a runnable application implementation. Product scope and the technical stack are still being evaluated.

## Project documents

- [Product vision and candidate MVP](docs/PRODUCT_VISION.md)
- [Proposed architecture overview](docs/architecture/overview.md)

Both documents are drafts. They distinguish the current repository state from proposed goals and architecture; they do not imply that described functionality has already been implemented.

## Current focus

1. Review and agree on the narrow MVP workflow.
2. Select the initial desktop platform and evaluate the UI/rendering stack with a small technical spike.
3. Record consequential choices in Architecture Decision Records (ADRs).
4. Scaffold a buildable application and automated quality checks.
5. Prove a small end-to-end scene workflow before expanding functionality.
